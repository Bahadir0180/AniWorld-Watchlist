This Program was completely written using Googles Gemini Ai and will probably never be updated unless Aniworld changes their Website in any meaningfull way.
I will also publish the Source Code so do whatever you want with it.
To use the App just start it login (don't worry ist just a webbrowser and your data stays on your PC) a Browser window will pop up don't touch it it will automatically sign you in and go through your watchlist one by one so this might take some time.
When the Program is finished you can sort by Genre, Films, Series and Favorites.
Under each Anime you will see a small box in 3 different Colors 
Gray(Not started the Anime), 
Yellow(started the Anime), 
Green(Finished the Anime).
You will also be able to see how many Seasons the Anime has and if they have a Movie.
The Program is in German (Aniworld is a German Website so Obv...)
if you want to compile the Source code you will need to install Node.js and npm install via git bash into the folder with the source files.
